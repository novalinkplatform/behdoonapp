## ۱. معماری و خلاصه فنی تغییرات کلیدی

در فازهای اخیر، مجموعه ارتقاهای حیاتی روی فرانت‌اند، پنل مدیریت، تجربه کاربری موبایل (Mobile UX)، وب‌اپلیکیشن (PWA) و هماهنگی زیرساخت کلادفلر اجرا شد که باعث ارتقای چشمگیر تبدیل کاربر، امنیت دسترسی‌ها و زیبایی بصری شده است.

### مهم‌ترین دستاوردها:
- **دسترسی سریع و آنی به تماس و چت:** کاربران در هر صفحه‌ای بدون نیاز به اسکرول یا گشتن، به شماره تماس و پشتیبانی دسترسی دارند.
- **چت مشتری هوشمند با شناسایی خودکار هویت:** بدون مجبور کردن کاربران وارد شده به ثبت مجدد مشخصات؛ و دریافت خودکار نام و موبایل از مهمانان.
- **پنل مدیریت چت به سبک تلگرام با دسترسی به سفارشات:** اپراتور همزمان با چت با مشتری، می‌تواند سفارش‌های فعال او را دیده، راننده یا تکنسین را اختصاص داده و فاکتور صادر کند.
- **جداسازی کامل مدیریت تماس و شبکه‌های اجتماعی:** تنظیم شماره‌ها، لینک‌های شبکه‌های اجتماعی و کلیدهای هدر در یک بخش مستقل، با پیشوند خودکار دامنه.
- **امن‌سازی فوتر عمومی:** حذف پیوند مستقیم پنل مدیریت پرسنل از دید عموم و خزنده‌های گوگل.
- **رفع مشکل پیش‌نمایش نصب PWA در گوشی‌ها:** ارائه اسکرین‌شات استاندارد با فرمت `narrow` و کیفیت عالی بدون متون قدیمی.

## ۲. سیستم تماس و چت یکپارچه در هدر

یکی از مؤثرترین ارتقاها، طراحی **هدر دومنظوره (موبایل و دسکتاپ)** با تمرکز بر تبدیل تماس و چت آنلاین است.

### ۲.۱. هدر در نمای موبایل (`mobile-top-contact-bar`)
در موبایل، به جای هدرهای شلوغ و سنتی، یک نوار باریک ثابت (Fixed/Sticky) طراحی شده است:
1. **سمت راست (تماس سریع):** دکمه تماس با آیکون گوشی تلفن و شماره خوانا با فرمت ارقام فارسی. کلیک روی آن فوراً پروتکل `tel:` را با شماره تمیز باز می‌کند.
2. **مرکز (برند و هویت):** لوگوی رسمی به همراه نام برند با فونت بولد و چشم‌نواز که با کلیک روی آن کاربر به صفحه اصلی هدایت می‌شود.
3. **سمت چپ (پشتیبانی برخط):** دکمه شیشه‌ای (Glassmorphism) حاوی آیکون چت و عبارت «پشتیبانی». با کلیک، پنل ویجت چت از پایین باز می‌شود.

```html
<!-- نمونه ساختار HTML هدر موبایل -->
<div class="mobile-top-contact-bar header-mobile-only">
  <a class="top-bar-link top-bar-call-btn" href="tel:09333256885" aria-label="تماس مستقیم">
    <span class="icon"><!-- آیکون تلفن --></span>
    <span class="top-bar-phone-text" dir="ltr">۰۹۳۳-۳۲۵-۶۸۸۵</span>
  </a>

  <a class="top-bar-brand" href="/" aria-label="صفحه اصلی">
    <img src="/favicon.svg" alt="بهبار" class="top-bar-logo" />
    <span class="top-bar-brand-title">بهبار</span>
  </a>

  <button type="button" class="top-bar-link chat-widget-toggle" aria-label="پشتیبانی آنلاین">
    <span class="icon"><!-- آیکون چت --></span>
    <span class="top-bar-support-text">پشتیبانی</span>
  </button>
</div>
```

### ۲.۲. جزایر تماس و پشتیبانی در دسکتاپ (`Desktop Contact Islands`)
در دسکتاپ، بخش ناوبری اصلی (منوها و دکمه ثبت سفارش) از دکمه‌های اقدام پشتیبانی تفکیک شده‌اند تا تمرکز کاربر برهم نخورد:
- **جزیره تماس (`phone-island`):** کپسول مستقل با پس‌زمینه لطیف، آیکون تلفن و شماره رسمی شرکت. با ماوس روی آن، انیمیشن تکان ملایم (Wiggle/Hover effect) توجه کاربر را به شماره جلب می‌کند.
- **جزیره چت (`chat-island`):** کپسول اختصاصی با دکمه باز کردن چت ویجت، برچسب «پشتیبانی آنلاین» و چراغ سبز آنلاین بودن پاسخگویی.
- **دانه‌های شناور شبکه‌های اجتماعی (`floating-social-beads`):** زنجیره‌ای زیبا از آیکون‌های گرد اینستاگرام، تلگرام، واتساپ و ایکس به صورت شناور که در هدر دسکتاپ قرار گرفته و کاربر را مستقیماً به کانال‌های اجتماعی برند هدایت می‌کند.

### ۲.۳. کشوی ناوبری موبایل (`mobile-nav-drawer`)
- دارای هدر موجی مدرن (`wavy-green-header`) با پس‌زمینه شیب‌دار (Gradient).
- کارت اقدامات فوری (CTA Box) شامل: دکمه ثبت فوری درخواست، دکمه تماس مستقیم شبانه‌روزی، و دکمه اختصاصی نصب وب‌اپلیکیشن (PWA).

## ۳. سیستم جامع پشتیبانی آنلاین و ویجت چت مشتری

سیستم چت بازطراحی‌شده به صورت یک کامپوننت مستقل (`src/components/ChatWidget.ts`) و استایل‌های اختصاصی (`src/styles/chat-widget.css`) توسعه داده شده است.

### ۳.۱. مدیریت هوشمند هویت کاربر (Identity & Onboarding)
سیستم قبل از ارسال پیام، کاربر را در ۳ سطح بررسی و هدایت می‌کند:
1. **سطح ۱ (کاربر لاگین کرده در سایت):** سیستم با تابع `getLocalCustomerInfo()` توکن و مشخصات پروفایل را بررسی می‌کند. اگر کاربر لاگین باشد، بدون درخواست مجدد فرم، چت را مستقیماً با نام واقعی و شماره ثبت‌شده او باز کرده و نشان تگ طلایی **«عضو سایت»** را در بالای چت نمایش می‌دهد.
2. **سطح ۲ (کاربر با سابقه چت قبلی):** در صورت وجود مشخصات معتبر در `localStorage`، سوابق فراخوانی شده و دکمه «ویرایش مشخصات» در اختیار وی قرار می‌گیرد.
3. **سطح ۳ (کاربر مهمان جدید):** کارت ورودی مدرن (Onboarding Card) نمایش می‌یابد که نام و نام خانوادگی به همراه شماره همراه (۱۱ رقم با پیش‌شماره معتبر ایران ۰۹) را می‌گیرد و ارقام فارسی را خودکار به ارقام انگلیسی تبدیل و اعتبارسنجی می‌کند.

### ۳.۲. امکانات پیام‌رسانی
- **تایپ پیام متنی** به همراه اموجی‌ها و انتر چندخطی.
- **ارسال عکس (`Image Attachment`):** دکمه انتخاب تصویر با پیش‌نمایش آنی در حباب پیام مشتری و پنل مدیریت، با ذخیره روی باکت امن یا مسیر ورکر.
- **ارسال موقعیت مکانی (`Location Sharing`):** دکمه دریافت لوکیشن با GPS مرورگر و تبدیل به لینک و پین نقشه زنده گوگل در چت.
- **سیستم پاسخگوی خودکار ۳ دقیقه‌ای (Grace Period Auto-Responder):**
  - هنگامی که مشتری پیامی ارسال می‌کند، تایمر ۳ دقیقه‌ای در بک‌اند فعال می‌شود.
  - اگر در طول ۳ دقیقه هیچ اپراتوری پیام را پاسخ ندهد، یک پیام رسمی خوش‌آمدگویی و پوزش بابت شلوغی خطوط به صورت خودکار با نوع `auto_reply` درج شده و کاربر را به تماس تلفنی یا ثبت شماره دعوت می‌کند.
  - اگر اپراتور زودتر پیام دهد، این پاسخ خودکار لغو می‌شود.
- **اعلان صوتی (Notification Chime):** پخش صدای دلنشین با وب‌آدیو هنگام دریافت پیام جدید از سمت پشتیبان.
- **تاریخ و زمان شمسی به سبک تلگرام:** تفکیک روزها با کپسول‌های تاریخ وسط صفحه («امروز»، «دیروز»، تاریخ خورشیدی) و درج ساعت فارسی در گوشه پیام.

## ۴. تحولات و ارتقاهای اساسی در پنل مدیریت

پنل مدیریت به نشانی `/management` (یا فایل مجزای `management.html`) دستخوش تغییرات کلیدی ساختاری، ظاهری و امنیتی شده است.

### ۴.۱. حذف لینک مدیریت از فوتر عمومی سایت
- **دلیل:** پیش‌تر لینک «ورود پرسنل و پنل مدیریت» در ستون چهارم فوتر عمومی سایت قرار داشت. این پیوند باعث جلب توجه کاربران عادی، خطر حملات Brute Force و ایندکس شدن صفحه لاگین ادمین در نتایج سرچ گوگل می‌شد.
- **تغییر اعمال شده:** پیوند مربوطه از کامپوننت [`Footer.ts`](file:///F:/behdoon/behdoon-web-and-api/src/components/Footer.ts) به طور کامل حذف شد.
- **روش دسترسی فعلی:** ورود فقط با تایپ دستی آدرس `/management` توسط همکاران و پرسنل با احراز هویت دو مرحله‌ای پیامکی (OTP) امکان‌پذیر است. همچنین تگ `noindex, nofollow` در هدر `management.html` لحاظ شده است.

### ۴.۲. بازطراحی پنل چت اپراتورها به سبک تلگرام (`ChatView.ts`)
- **صفحه دو ستونه مدرن:**
  - **ستون راست (فهرست گفتگوها):** نمایش لیست چت‌ها با آواتارهای گرادیانتی بر اساس حروف اول نام، فیلترهای تفکیکی («همه گفتگوها»، «چت‌های من»، «بدون اپراتور»، «آرشیو شده»)، وضعیت پیام خوانده نشده با بج شمارنده قرمز، و پیش‌نمایش متن یا نوع پیام (تصویر 📷 یا موقعیت مکانی 📍).
  - **ستون چپ (فضای گفتگو):** هدر شفاف حاوی نام کاربر، شماره تماس، وضعیت آنلاین، دکمه ارجاع و انتصاب اپراتور، و تاریخچه زمانی دقیق پیام‌ها.
- **کشوی یکپارچه سفارشات متصل به شماره مشتری (Integrated Orders Drawer):**
  - اپراتور برای بررسی پیشینه مشتری نیازی به رفتن به تب سفارشات ندارد.
  - سیستم با شماره تلفن جاری مشتری، تمام درخواست‌های فعال و قبلی او را در یک کشوی کشویی بغل صفحه چت فراخوانی می‌کند.
  - اپراتور می‌تواند **مستقیماً از همان صفحه چت**، وضعیت درخواست را تغییر دهد، راننده یا تکنسین را اعزام کند، و فاکتور تفکیکی رسمی را باز کرده یا چاپ کند.

### ۴.۳. ماژول مستقل مدیریت تماس و شبکه‌های اجتماعی (`ContactManagerView.ts`)
پیش از این، تنظیمات تماس در میان انبوه تنظیمات صفحه Settings گم شده بود. اکنون یک دسته مجزا در منوی اصلی پنل مدیریت ساخته شده است:
- **کنترل جزایر هدر:** سوئیچ روشن/خاموش کردن نمایش شماره تلفن و چت در هدر سایت.
- **حالت‌های نمایش چت:** تنظیم روی «فقط در هدر»، «آیکون شناور در گوشه صفحه» یا «غیرفعال».
- **فرمت‌دهی خودکار تلفن:** با وارد کردن شماره ساده، سیستم لینک استاندارد `tel:` را خودکار استخراج و ست می‌کند.
- **پیشوند خودکار شبکه‌های اجتماعی (Domain Auto-Prepend):**
  - اگر مدیر در کادر تلگرام فقط آیدی بنویسد (مثلاً `behbar_co`)، سیستم به طور خودکار آن را به `https://t.me/behbar_co` تبدیل می‌کند.
  - برای اینستاگرام: خودکار به `https://instagram.com/...` تبدیل می‌شود.
  - برای واتساپ: شماره به صورت لینک مستقیم چت واتساپ ذخیره می‌شود.

### ۴.۴. صدور و چاپ پیشرفته فاکتور رسمی (`InvoiceModal.ts` & `invoice.ts`)
- طراحی فرم صورت‌حساب استاندارد مالی با کد پیگیری یکتا.
- جدول تفکیک هزینه‌های خدمات، کرایه، قطعات، تخفیف، و جمع کل به تومان با حروف و عدد فارسی.
- چاپ شیک با فرمت `@media print` که تمامی منوها و دکمه‌های صفحه را حذف کرده و فقط برگه رسمی آ۴ تمیز را جهت ارائه به مشتری پرینت می‌گیرد.

## ۵. ارتقای تجربه موبایل، PWA و رفع باگ‌های نمایش

### ۵.۱. اصلاح کامل اسکرین‌شات‌های PWA در کروم موبایل
- **ریشه مشکل قبلی:** هنگام نمایش بنر نصب وب‌اپلیکیشن (Install App) در اندروید، کروم یک شیت تمام‌صفحه به کاربر نشان می‌دهد. اگر مانیفست فاقد اسکرین‌شات استاندارد با مشخصه `form_factor: "narrow"` باشد، کروم از تصاویر عریض متفرقه (یا دموهای قدیمی ژاکت) استفاده می‌کرد.
- **راه‌حل پیاده‌سازی شده:**
  1. ساخت اسکریپت اختصاصی با کتابخانه `sharp` در مسیر [`scripts/generate-pwa-showcases.mjs`](file:///F:/behdoon/behdoon-web-and-api/scripts/generate-pwa-showcases.mjs).
  2. ایجاد تصویر اسکرین‌شات موبایل به ابعاد `720x1280` پیکسل با نسبت ۱۶:۹ عمودی حاوی المان‌های واقعی برنامه در مسیر `public/screenshot_mobile.png`.
  3. ایجاد تصویر دسکتاپ به ابعاد `1440x900` پیکسل در مسیر `public/screenshot_desktop.png`.
  4. بازنویسی آرایه `screenshots` در `public/site.webmanifest`:

```json
"screenshots": [
  {
    "src": "/screenshot_mobile.png",
    "sizes": "720x1280",
    "type": "image/png",
    "form_factor": "narrow",
    "label": "سامانه هوشمند ثبت آنلاین خدمات در تهران"
  },
  {
    "src": "/screenshot_desktop.png",
    "sizes": "1440x900",
    "type": "image/png",
    "form_factor": "wide",
    "label": "پیش‌نمایش سامانه ثبت درخواست بهدون"
  }
]
```

### ۵.۲. اصلاح هماهنگی و اندازه آیکون‌های فوتر در موبایل
- در موبایل، آیکون‌های شبکه‌های اجتماعی و نمادهای اعتماد بزرگ‌نمایی نامناسب داشتند. با تنظیم گرید فلکس، حذف استایل‌های تداخلی و اعمال عرض حداکثر و پدینگ متناسب در [`src/styles/footer.css`](file:///F:/behdoon/behdoon-web-and-api/src/styles/footer.css)، فوتر در تمامی ابعاد موبایل (از ۳۲۰ پیکسل تا تبلت) کاملاً تراز و چشم‌نواز شد.

### ۵.۳. بنر و مودال هوشمند نصب PWA (`PwaInstallPrompt.ts`)
- اضافه شدن بنر پایین صفحه با قابلیت تشخیص عدم نصب بودن برنامه.
- مودال راهنمای نصب تفکیکی برای آیفون (دکمه Share در سافاری سپس Add to Home Screen) و اندروید با انیمیشن‌های ملایم.

## ۶. ساختار پایگاه‌داده و اندپوینت‌های بک‌اند

در دیتابیس Cloudflare D1 و اسکریپت ورکر (`worker/index.ts`)، جداول و اندپوینت‌های چت به شکل بهینه و سبک پیاده‌سازی شده‌اند:

### ۶.۱. اسکیما جدول گفتگوها (`chat_conversations`)
```sql
CREATE TABLE IF NOT EXISTS chat_conversations (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  token TEXT NOT NULL UNIQUE,
  customer_name TEXT,
  customer_phone TEXT,
  status TEXT DEFAULT 'open', -- 'open', 'closed', 'archived'
  assigned_staff_id INTEGER,
  unread_count INTEGER DEFAULT 0,
  last_message TEXT,
  last_message_type TEXT DEFAULT 'text',
  last_message_at TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_chat_conversations_token ON chat_conversations(token);
```

### ۶.۲. اسکیما جدول پیام‌ها (`chat_messages`)
```sql
CREATE TABLE IF NOT EXISTS chat_messages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  conversation_id INTEGER NOT NULL,
  sender TEXT NOT NULL, -- 'customer' یا 'staff'
  staff_id INTEGER,
  staff_name TEXT,
  staff_avatar TEXT,
  text TEXT NOT NULL,
  type TEXT DEFAULT 'text', -- 'text', 'image', 'location', 'auto_reply'
  created_at TEXT NOT NULL,
  FOREIGN KEY (conversation_id) REFERENCES chat_conversations(id) ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS idx_chat_messages_conv ON chat_messages(conversation_id);
```

### ۶.۳. مهم‌ترین اندپوینت‌های ورکر (`worker/index.ts`)
- `GET /api/chat/:token`: دریافت وضعیت گفتگو و آخرین پیام‌ها برای کلاینت کاربر.
- `POST /api/chat/:token/messages`: ارسال پیام جدید از سمت کاربر (همراه با تریگر منطق Auto-reply).
- `GET /api/chat/admin/conversations`: فهرست مکالمات برای اپراتور پنل مدیریت با فیلترها.
- `GET /api/chat/admin/conversations/:id/messages`: واکشی پیام‌های یک گفتگوی خاص.
- `POST /api/chat/admin/conversations/:id/messages`: پاسخ اپراتور و بازنشانی وضعیت خوانده‌نشده.
- `POST /api/chat/admin/conversations/:id/assign`: ارجاع چت به یک اپراتور مشخص.
- `POST /api/chat/admin/conversations/:id/status`: تغییر وضعیت چت (بستن یا بایگانی).
