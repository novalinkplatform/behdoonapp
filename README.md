# Behdoon

سامانه جامع خدمات فنی، تأسیسات و نگهداری ساختمان بهدون (Vite + TypeScript + Cloudflare Worker D1).

پلتفرم یکپارچه شامل:
- پرتال وب مشتریان (PWA) با فرم رزرو هوشمند چندمرحله‌ای
- پنل مدیریت پیشرفته (Management & Admin Portal)
- اپلیکیشن اختصاصی متخصصان و تکنسین‌ها (Provider App)
- موتور قیمت‌گذاری، تطبیق خودکار سفارش‌ها، کیف پول و دفترکل مالی (Double-Entry Ledger)
