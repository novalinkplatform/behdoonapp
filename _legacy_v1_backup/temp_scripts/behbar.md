# پروژه: بهبار (Behbar)

تو یک Senior Frontend Engineer، Product Designer و UI/UX Designer هستی.

می‌خواهم یک وب‌سایت حرفه‌ای فارسی با نام **«بهبار»** بسازی.

نام برند:

**بهبار | Behbar**

شعار پیشنهادی:

**«حمل و جابه‌جایی، ساده‌تر از همیشه»**

## 1. هدف محصول

بهبار یک پلتفرم برای آگهی و درخواست خدمات حمل‌ونقل و جابه‌جایی است.

کاربران می‌توانند برای موارد زیر درخواست ثبت کنند:

- اثاث‌کشی
- حمل بار
- حمل وسایل منزل
- وانت
- نیسان
- خاور
- کامیون
- حمل بار بین‌شهری
- کارگر اسباب‌کشی
- جابه‌جایی وسایل سنگین
- خدمات باربری

در آینده قرار است بهبار به یک Marketplace حمل‌ونقل تبدیل شود که در آن:

**مشتری → درخواست حمل ثبت می‌کند**

و

**راننده / باربری / شرکت حمل‌ونقل → درخواست‌ها را می‌بیند و پیشنهاد می‌دهد.**

اما در این مرحله فقط باید **نسخه اول صفحه اصلی و UI اولیه محصول** ساخته شود.

# 4. هویت بصری

برند:

**بهبار**

رنگ اصلی را در طیف آبی/سرمه‌ای حرفه‌ای انتخاب کن.

رنگ‌های پیشنهادی:

- Primary: آبی عمیق
- Secondary: آبی روشن
- Background: سفید و خاکستری بسیار روشن
- Text: خاکستری بسیار تیره
- Success: سبز
- Warning: نارنجی

رنگ‌ها را به صورت CSS Variables تعریف کن تا بعداً بتوانیم Brand Identity را تغییر دهیم.

مثلاً:

```css
:root {
  --primary: ...;
  --primary-dark: ...;
  --background: ...;
  --surface: ...;
  --text: ...;
  --muted: ...;
  --success: ...;
  --border: ...;
}
```

# 19. Architecture

کد را از ابتدا تمیز و قابل توسعه بنویس.

ساختار پیشنهادی:

```text
src/
├── components/
├── sections/
├── styles/
├── assets/
├── data/
├── utils/
└── main.js
```

اگر TypeScript انتخاب کردی:

```text
src/
├── components/
├── sections/
├── types/
├── data/
├── utils/
├── styles/
└── main.ts
```

Componentها و Sectionها را تا حد منطقی جدا کن.

از یک فایل عظیم `main.js` که همه‌چیز در آن ریخته شده خودداری کن.

در پایان:
